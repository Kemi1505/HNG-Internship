## 📖 Overview

This project is a simple RESTful API built with **NestJS**.
It exposes a single endpoint `/me` that returns your profile information along with a **random cat fact** fetched dynamically from the [Cat Facts API](https://catfact.ninja/fact).

## ⚙️ Technologies Used

- **NestJS** — Node.js framework for scalable backend applications
- **TypeScript** — Strongly typed JavaScript
- **Axios (@nestjs/axios)** — For external HTTP requests
- **RxJS** — Reactive programming utilities
